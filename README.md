# dsh-edict-boot · 奏折开机动画

给 DeepSeek Harness 的开机片头：**一卷奏折摊开，打开就是办公的地方**。

一段实拍的折装奏折素材——朱红缎面压金线蟠龙、白纸手风琴式内页，六秒里从
合着的一卷摊成完整长卷。配「上朝·宫廷内侍」的低沉人声与一段十六秒的宫廷乐。
**后半程奏折化进雾里，DSH 主界面同时从雾里浮出来。**

## 安装

从 Git 安装（推荐）：

~~~sh
dsh plugin --profile desktop add github:<你的用户名>/dsh-edict-boot
~~~

或用本地路径：

~~~sh
dsh plugin --profile desktop add /path/to/dsh-edict-boot
~~~

**装完必须重启一次 DSH**，然后在窗口里按 **Ctrl+Shift+R** 硬刷新——
DSH 的客户端 bundle 带 `max-age=31536000, immutable`，普通 F5 拿不到新东西。

### 卸载

~~~sh
dsh plugin --profile desktop remove dsh-edict-boot
~~~

## 关于声音

浏览器有一条硬规则：**没有用户手势，页面不许出声**。这不是实现问题，
任何网页都绕不过（实测会抛 `NotAllowedError: play() failed because the user
didn't interact with the document first`）。

所以：

- 动画永远自动播放，**默认静音**
- 想听声音，点左下角的 **🔈 点击开启声音**
- 点过之后本次会话不再提示（记在 sessionStorage）
- 下次开机要再点一次（浏览器按会话授权）

## 调校

**DSH 设置页 →「奏折开机动画」**：

| 项 | 说明 |
|---|---|
| 启用 | 总开关。关掉后 Host 半侧**一行都不注入**，页面里连脚本都没有 |
| 允许跳过 | 右下角「跳过」按钮 + 随时按 **Esc** |
| 节奏 | 0.5×–2.5×，1× 约 6 秒 |
| 使用实拍视频 | 关掉则回落到纯 CSS 演绎（无素材也能用） |

配置存在 `$DSH_HOME/edict-boot.json`。文件写坏、删掉、或没有写权限，
都会安静回落到默认值——**不会**变成启动失败。

## 平台支持

| | web profile | 桌面端 |
|---|---|---|
| 首屏注入 | `webServer.tapIndex` 改写 index.html | 浏览器半侧自举 |
| 为什么不一样 | — | 桌面端走 `dsh-app://` 自定义协议，**不经过 tapIndex** |

桌面端这一条是插件里那套自举逻辑存在的唯一原因。没有它，动画在桌面端
永远不出现——代码看着没问题、web 端也正常，就是桌面端一片空白。

两条路径通过 `__DSH_EDICT_BOOT__` 握手指记互斥，**绝不会播两遍**。

## 技术要点

### 首屏不能闪

自举要依次完成「取配置 → 拉 scene.js → 建浮层 → 视频出首帧」，
这几步之间页面是可见的。所以：

1. `bootSelf()` 第一行就用内联样式盖一层遮罩，不等任何外部资源
2. 视频模式下 `.ed-root` **一插入就是不透明的**，不能像 CSS 版那样等
   `.ed-ready` 才淡入
3. 等 `video.readyState >= 2`（真能出画面）之后，再撤遮罩

实测：修复前有 16 个采样点露出主界面，修复后 **0 个**。

### 收尾是交叉虚化，不是淡出

整层 `opacity → 0` 是「把幕布扯掉」的观感。现在是两条同时跑的曲线：

| 谁 | 怎么变 | 时长 |
|---|---|---|
| 奏折本体 | `scale(1.08)` + `blur(22px)` + 透明度归零 | 1300ms |
| 浮层底色与暗角 | 透明度归零，底下的 DSH 透出来 | 1300ms |

不等视频播完才动——提前 1500ms 起手，让「还在摊开」和「开始化开」重叠。

### 声音素材没有做任何处理

人声是原始录音**原样使用**（SHA256 与源文件一致）。前面版本做过降调、时间拉伸、
混响、低频衬底，结果全是问题：

- 降调女声冒充男声 → 共振峰不对，一听就是"慢放的女人"
- 相位声码器拉伸 → 峰值/RMS 达 31.8（正常 3-5），大量冲激伪影
- 手工混响包络 → 尾部硬切断，留下 0.47 的样本跳变
- 70/95Hz 低频衬底 → 20-60Hz 暴涨 22.5 dB，小喇叭放不出来变成"噗噗"声

素材本身就是干净的（15-40Hz 能量仅 0.00048，最大样本跳变 0.19）。
**素材好就别动它。**

## 自测

~~~sh
node test/smoke.mjs
~~~

用假的 webServer 驱动真实的 `lib/index.js`，断言路由、Range/ETag、
配置读写、首屏注入。`DSH_HOME` 指向临时目录，不碰真实配置。

## 没有构建步骤

`lib/` 里是可直接运行的产物：Host 半侧是原生 ESM，客户端半侧是手写的
ModuleLoader bundle。改完重启 DSH 即可，不需要编译。

预览页：`lib/preview.html`，直接双击打开，或走 `/dsh-edict/preview`。
